# 🛡️ ImpactGuard — Entire Graph Intelligence Engine

**Live Domain**: [https://prajwalmallikarjun2008-ship-it.github.io/entire-live/](https://prajwalmallikarjun2008-ship-it.github.io/entire-live/)

ImpactGuard is a developer decision and adjudication dashboard built for **Track 2: Build with Graph Intelligence**.

## 🌟 Key Features
- **Dynamic Blast Radius Engine**: Calculates downstream function & route impact using `entire graph impact`.
- **Evidence Lineage Inspector**: Maps structural nodes back to source code definitions & lines.
- **Adjudicated Test Runner**: Evaluates test coverage gaps using `entire graph verify`.
- **PR Audit Generator**: Exports Markdown compliance summaries.
